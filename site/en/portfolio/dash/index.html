Ldash

Everything you need

A personal ops dashboard in the laden.no language: apps, monitor, calendar, sticky notes and subscriptions — Ctrl+` and you are in.

Surface

Type
Desktop app
Stack
JavaScript, Python, C#
Role
Product development

Challenge

We wanted a light, hack-like dashboard that opens on a shortcut: your apps, host monitoring, calendar, sticky notes and subscription overview — without the heavy enterprise feel.

Move

Ldash is written in JavaScript. The same HTML page is the dashboard on every system, in the laden.no palette (void, hack-green, cyan). Widgets can be dragged in edit mode, size classes adapt, and Control gathers the settings. Python does the desktop work behind that page. Windows and Mac ship that host inside a C# window, Android is Kotlin, and the iPhone version is Swift.

Stack

The screen is written in JavaScript, in ordinary script files, with HTML and CSS. Titles use Orbitron. Python is the desktop host: it reads the machine, launches programs, and keeps the vault. On Linux that host opens a GTK 4 window with WebKit. Windows is a C# window on Microsoft WebView2, with a private Python runtime in the installer, so you do not install Python yourself. Mac is a C# window on the system WebKit, with a private Python 3.12 runtime. Android is written in Kotlin and shows the same JavaScript in the system WebView.

Download the prototype

Mac · Windows · Linux · Android

Unsigned test builds. On a Mac, if Gatekeeper asks, right-click the .pkg and choose Open. On Windows, if SmartScreen warns, choose More info and run it anyway. On Linux, unpack the .tar.gz and run sh linux/install.sh. On Android, allow install from this source.

iPhone

Mock iPhone — Open source. Apple’s terms block a normal install. No .ipa.

The iPhone app is written in Swift. It shows the same JavaScript dashboard in the system WebKit, built for the pocket. A narrow screen stacks the panels; at desktop width they stay in the grid. There is no global hotkey and no terminal. You leave with the Home gesture, and the vault title stays your callsign. A launcher that is a shell command does not run, and the phone does not list other apps or their windows. If no vault master is set, Unlock asks for Face ID or the device passcode — the text in that box is not checked. No install file. Apple's terms don't allow a normal sideload download, so the iPhone app is the open-source code instead — another point for open source. The Xcode project is ready; an .ipa is not.

Result

Download the prototype for Mac, Windows, Linux or Android. The builds are unsigned test packages — expect a warning the first time. That is the point: a fast way to feel the product. Linux is the .tar.gz: unpack it and run sh linux/install.sh.
