Ldash

Everything you need

Personlig ops-dashboard i laden.no-språket: programmer, monitor, kalender, sticky notes, abonnementer — Ctrl+` og du er inne.

Type
Desktop-app

Utfordring

Vi ville ha et lett, hack-aktig dashboard som åpnes på snarvei: egne programmer, host-monitorering, kalender, sticky notes og abonnementsoversikt — uten tung enterprise-følelse.

Grep

Ldash er skrevet i JavaScript. Den samme HTML-siden er dashbordet på alle systemer, i laden.no-paletten (void, hack-green, cyan). Widgets kan dras i edit-modus, størrelsesklasser tilpasses, og Control samler innstillingene. Python gjør skrivebordsarbeidet bak siden. Windows og Mac har den verten i et C#-vindu, Android er Kotlin, og iPhone-versjonen er Swift.

Stack

Skjermen er skrevet i JavaScript, i vanlige skriptfiler, med HTML og CSS. Titlene bruker Orbitron. Python er skrivebordsverten: den leser maskinen, starter programmer og holder vaulten. På Linux åpner den verten et GTK 4-vindu med WebKit. Windows er et C#-vindu på Microsoft WebView2, med en privat Python-kjøretid i installeren, så du slipper å installere Python selv. Mac er et C#-vindu på systemets WebKit, med en privat Python 3.12-kjøretid. Android er skrevet i Kotlin og viser det samme JavaScriptet i systemets WebView.

Last ned prototypen

Mac · Windows · Linux · Android

Usignerte testbygg. På Mac, hvis Gatekeeper spør, høyreklikk .pkg-filen og velg Åpne. På Windows, hvis SmartScreen advarer, velg Mer info og kjør likevel. På Linux pakker du ut .tar.gz og kjører sh linux/install.sh. På Android tillater du installasjon fra denne kilden.

macOS v1.0 (.pkg)Windows v1.0 (.exe)Linux v1.0 (.tar.gz)Android v1.0 (.apk)

iPhone

Mock iPhone — Åpen kildekode. Apples vilkår sperrer en vanlig installasjon. Ingen .ipa.

iPhone-appen er skrevet i Swift. Den viser det samme JavaScript-dashbordet i systemets WebKit, bygget for lommen. Smalt skjermbilde stabler panelene; i skrivebordsbredde ligger de i rutenettet. Ingen global hurtigtast og ingen terminal. Du går ut med Hjem-gesten, og vault-tittelen blir kallesignalet ditt. En oppstarter som er en skallkommando kjører ikke, og telefonen lister verken andre apper eller vinduene deres. Er ingen vault-master satt, ber Lås opp om Face ID eller enhetens kode — teksten i feltet sjekkes ikke. Ingen installasjonsfil. Apples vilkår tillater ikke en vanlig nedlasting du kan sideloade, så iPhone-appen er åpen kildekode i stedet — enda et poeng for åpen kildekode. Xcode-prosjektet er klart; en .ipa finnes ikke.

Resultat

Du kan laste ned prototypen til Mac, Windows, Linux eller Android. Byggene er usignerte testpakker — forvent en advarsel første gang. Det er meningen: rask vei til å kjenne på produktet. Linux er .tar.gz-filen: pakk ut og kjør sh linux/install.sh.
