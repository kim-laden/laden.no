06How to work a station

  1. Open a booth from the Lounge board (or /labs/<slug>/).
  2. Read the brief — scope, goal, hints exist for a reason.
  3. Hunt ethically inside the demo — don’t spray production, don’t pivot off-scope.
  4. Submit the flag LLZ{…} for XP.

These are teaching labs. PoC, not pwn. If you’re stuck, ask Caleb — after you’ve actually read the booth.

07LLC console

Your private workstation in the browser. Open it with:

  • Backtick ` — works with Norwegian AltGr layouts too
  • Floating llc$ control, or the bottom Console tab on mobile
  • /labs/?llc=1 or /terminal/

Prompt looks like user@llc. Home is /z/labz/<user> with Documents / Downloads. Sessions persist until you clear. Nets are fictional only (labnet 10.13.37.0/24 and friends) — never point scanners at the real internet.

Command groups

  • Filesystem — pwd ls cd cat head tail tree find mkdir touch rm rmdir cp mv echo grep
  • Z Drive — df / zquota, zshare, zunshare
  • Networks — ip ifconfig iwconfig iw labcrack-ng*
  • Scanners — lmap, mzfconsole
  • Helpers — curl wget base64 rot13 xxd jwt hashid (+ md5/sha*)
  • Session — help hint clear whoami id uname manuals

Deep docs live at /labs/manuals/. In LLC, type manuals or man <tool>. Type zguide or bible for this page.

22Workarounds / FAQ

Login failed?

Use https://laden.no. HTTP login is allergic to itself.

Page looks haunted after a deploy?

Hard-refresh (Ctrl/Cmd+Shift+R). Caches love old ghosts.

Backtick won’t open LLC?

Norwegian layouts: AltGr + the key that makes `. Or tap Console / floating llc$.

Only three stations?

You’re a guest. Badge up for the full board — free trio is scope-first, robots-redux, reflect-101.

Where’s LLD / “dev.”?

Account → LLD opt-in checkbox → Save. Then the Lounge CTA can appear.

Lab ID card off-screen?

Desktop: hover Login / your name. Mobile: tap Login / name when logged in.

Z Drive full?

Quota is real-ish (~10 MB fiction). Clean Downloads, unshare, try again.

Can I scan the real internet from LLC?

No. Fictional nets only. Pointing scanners at live hosts is how you leave the lounge the hard way.

Golden rule?

Scope first. Always. Written permission beats curiosity.

23Ethics closer
