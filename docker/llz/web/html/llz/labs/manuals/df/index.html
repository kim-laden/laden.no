df

Show Z Drive (LabDrive) quota: used, free, and max.

Aliases: zquota · quota

Synopsis

Show Z Drive (LabDrive) quota: used, free, and max.

Syntax

df
zquota
quota

Options / Flags

  • No flags — all three names call the same quota endpoint.

Examples

Copy-paste into LLC (backtick ` to toggle)

df
zquota

Notes

  • Home: /z/labz/<you> with Documents · Downloads.
  • Default quota ~10 MB (login required for full LabDrive).
  • Manage shares and files also from /account/.
  • Decoy FS flag hunt lives under /z/opt/….
