base64

Encode or decode Base64 from a string or file.

Synopsis

Encode or decode Base64 from a string or file.

Syntax

base64 [-d|--decode] <file|str>

Options / Flags

  • -d / --decode — decode mode
  • If path resolves to a file, its contents are used

Examples

Copy-paste into LLC (backtick ` to toggle)

base64 hello
base64 -d b64-sample.txt
base64 -d SGVsbG8=

Notes

  • Behaves as implemented in LLC — educational browser workstation.
